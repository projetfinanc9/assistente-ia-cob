# Constru AI Connect

Assistente de IA inteligente para gerenciamento de cobranças e integração com Sienge.

## Tecnologias utilizadas

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- FastAPI (Python)
- WhatsApp Cloud API

## Como executar

### Frontend
```sh
npm install
npm run dev
```

### Backend
```sh
cd backend
pip install -r requirements.txt
python main.py
```
